# i18n

Last verified against commit HEAD.

## Library
Minimal in-house runes-based implementation on top of Intl. See src/renderer/lib/i18n/.

## Locale files
src/renderer/locales/<code>.lang. Format: metadata header (@locale, @nativeName, @englishName, @direction, @translators, @reviewed) then key = value entries.

## Auto-discovery
Adding a language requires adding exactly one .lang file. The language selector is populated from metadata headers.

## Never translated
Git commit messages, Discord embeds, changelogs, modrinth.index.json, logs, developer logs.
